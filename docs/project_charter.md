# Hospital Operations Analytics

## Business Problem

Hospital leadership needs to better understand operational performance, patient flow, and quality-of-care indicators to support data-driven decision-making.


## Stakeholders

- Director of Operations
- Hospital Executive Team
- Quality Improvement Department
- Clinical Managers
  

## Objectives

- Analyze patient admissions
- Evaluate length of stay
- Explore laboratory utilization
- Identify readmission patterns
- Assess operational performance
- Develop executive recommendations


## Key Performance Indicators (KPIs)

- Total admissions
- Average length of stay
- Readmission rate
- Laboratory procedures per patient
- Medications per patient
- Average patient age
- Admissions by type
- Discharge disposition


## Deliverables

- SQL analysis
- Python data cleaning
- Exploratory Data Analysis (EDA)
- Executive dashboard
- Business recommendations
- GitHub documentation
